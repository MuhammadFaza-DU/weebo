# PRD — Definisi Produk

**Status:** kosong. Menunggu arah produk.

**Untuk apa dokumen ini.** Menjawab **apa yang dibangun dan untuk siapa**. Tidak menjawab bagaimana
(itu `docs/PHASES.md` + file fase) dan tidak menjawab kenapa begitu (itu `docs/DECISIONS.md`).

| Dokumen | Menjawab | Kalau bentrok |
|---|---|---|
| `docs/PRD.md` (ini) | Apa, untuk siapa, dan bagaimana kualitasnya diukur | PRD menang soal definisi user, prioritas fitur, dan target kualitas |
| `docs/PHASES.md` + `docs/phases/` | Bagaimana dan kapan | File fase menang soal urutan dan pembagian task |
| `docs/DECISIONS.md` | Kenapa begitu | ADR menang soal pilihan teknis |
| `docs/RULES.md` | Kewajiban lomba | RULES menang atas semuanya soal kewajiban lomba |

**Larangan.** PRD tidak boleh memuat task, estimasi waktu, atau nama file kode.

---

## Status berkas ini

**Kosong.** PRD sebelumnya dihapus pada 2026-10-21 bersama ide produk yang dibatalkan. Isinya masih
bisa dibaca di riwayat git dan tag `stable-2026-10-21-v1`.

Dokumen ini akan diisi setelah arah produk baru disepakati. Sampai saat itu, tidak ada definisi user,
user story, maupun KPI yang berlaku.

**Jangan mengisi bagian mana pun di sini dengan asumsi.** Setiap klaim tentang produk harus berasal
dari keputusan user yang tercatat di `CHECKPOINT.md` atau `docs/DECISIONS.md`.
